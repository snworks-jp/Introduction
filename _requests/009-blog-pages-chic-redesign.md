# 009 BLOG（一覧・記事ページ）をトップページと同じシックなデザインに揃える

- 対象: Introductionサイト（`blog/index.html`、`blog/*.html`の既存記事9本、`scripts/template-curation.html`、`scripts/release.py` 内の `INDEX_TMPL`）
- 優先度: 中（トップだけ新デザインで、BLOGに入ると旧デザインに戻るため、印象がちぐはぐ）
- 作成日: 2026-11-01
- 関連: 007（トップページのデザイン変更。実装済み）、008（アイコン。実装済み）

## 経緯
007では、トップページ（`index.html`）だけを対象にして、BLOG・各ページへの展開は
「トップの仕上がりを見てから別の依頼書で」と書いていた。今回、二階堂さんから
「BLOGのリンク先のデザインが変わっていない」との指摘があり、その依頼書がこの009。
（指示漏れではなく、007の範囲を意図的に絞っていたため。）

## 提案内容

BLOGの一覧ページと記事ページを、トップページと同じ配色・書体・雰囲気にする。
記事の本文・リンク・構造（`class="src"` など）は変えない。**CSSの変更が中心**。

### 1. 配色（記事ページ・一覧ページの `:root` の値を差し替える）
現在の記事ページは、生成り色の背景と赤茶色のアクセントで、システムの明暗設定に合わせて暗くもなる作りになっている。
これを、トップと同じ**常時ダーク（黒＋金）**に変更する。

```css
:root { --bg:#141311; --surface:#1b1a17; --ink:#ece6da; --muted:#a39b8c;
        --line:#2c2a25; --accent:#c9a96a; --accent-ink:#141311; --soft:#1b1a17; }
```
- `@media (prefers-color-scheme: dark) { ... }` のブロックは不要になるので削除する（常にダークのため）。
- 記事の本文色 `#ece6da` と背景 `#141311` の組み合わせは読みやすさ（コントラスト）が十分。
  補助文字 `#a39b8c` も同様に問題ない。

### 2. 書体
- 見出し（h1, h2）: 明朝体 `"Shippori Mincho","Hiragino Mincho ProN","Yu Mincho",serif`、字間 0.04em。
- 本文: 現在のゴシック体（`"Hiragino Sans","Yu Gothic","Meiryo",system-ui,sans-serif`）のまま、行間 1.9 を維持。
  長い文章を読むページなので、太さは変えない（トップのように細くしない）。
- 外部フォントは使わず、システムフォントだけにする（007と同じ方針）。

### 3. 部品の見た目
- 上部に、トップと同じ細い罫線つきのバー（左に `SN WORKS`、英字ロゴ）を置く。
  現在のパンくず（`SN Works › BLOG`）は、見出しの上にそのまま残してよい。
- `.src`（参考記事のカード）、`.box`、`.note`: 角丸を現在の 8〜10px から **2〜4px** に小さくし、
  枠線は `--line`。ホバー時は枠線を `--accent`（金）にする。影はつけない。
- `.cta`（ボタン）: 塗りつぶしをやめ、トップと同じ「テキスト＋金の下線」にする。
- `.src .go`（「→」リンク）の色は金（`--accent`）のまま。
- フッターは、トップと同じ構成（`SN WORKS`、プライバシーポリシー、© 2026 SN Works）に揃える。
- アイコンのタグは、記事・一覧とも実装済みなので、そのまま維持する。

### 4. BLOG一覧ページ（`blog/index.html`）
- 記事カードは、トップのBLOGと同じ**1行リスト**（日付／タイトル／説明／→）にする。
  日付は `2026.10.31` の形式。上下に罫線。
- カードのHTML構造（`release.py` の `card()` の出力）は変えず、CSSだけで見た目を変える。
  トップは007で同じ方法を採用済みなので、そのCSSを流用できるはず。
- セクション見出し（`SECTION_TITLES`、カテゴリ名）は、明朝体＋英字の小ラベルを添える形にしてよい。

### 5. 実装の進め方（再発防止）
1. まず `scripts/template-curation.html` と `INDEX_TMPL` を直す（今後の記事が自動で新デザインになる）。
2. 既存の記事9本（`blog/*.html`、一覧の `blog/index.html` を除く）の `<style>` ブロックと
   ヘッダー・フッターを、同じ内容に置き換える。9本とも同じ共通CSSなので、1つのスクリプトでまとめて置き換えられるはず。
   その際、**本文・タイトル・メタ情報・参考記事のリンク（`class="src"`）は変更しない**こと。
3. `release.py` の `--no-release` で再生成して、一覧・トップが壊れないことを確認する。
4. 確認: 全記事が新デザインで表示される／スマホ幅（375px前後）で横スクロールがない／
   リンクの色が見やすい／既存のURLが変わっていない／sitemap・`googleb39988c901ff592a.html` は変更しない。

### 6. 今回の範囲に含めないもの
- `pages/ScoreMate_Introduction.html`、`pages/concert-calendar.html`、`pages/privacy.html`は、
  それぞれ独自の作りになっているため、別の依頼書（010として出す予定）にする。
  カレンダーは入力フォームなどがあるので、BLOGとは分けて慎重に進めたい。
- 文章の内容や記事の追加は行わない。

## 理由・根拠
- 現状、トップは黒＋金の高級感のあるデザインだが、BLOGの一覧・記事に入ると生成り色＋赤茶色の旧デザインになり、
  別のサイトに見える。サイト全体の統一感がなく、せっかくの印象の向上が途切れる。
- 記事ページは、全記事が同じ共通CSSで作られているため、色の変数（`:root`）を差し替えるだけで、
  大部分は短時間で揃えられる。

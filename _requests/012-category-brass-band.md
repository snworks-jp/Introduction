# 012 BLOGの分類に「ブラスバンド」を追加する

- 対象: `scripts/release.py`（分類の辞書）、記事案の書式、必要に応じて既存記事の `<meta>`
- 優先度: 低〜中（010の実装と同時にやるのが一番簡単）
- 作成日: 2026-11-01
- 関連: 010（BLOGの構造改善。`topic` / `instrument` の分類を導入）
- ユーザー承認: 二階堂さんの指示「カテゴリーにブラスバンドを追加して」

## 前提（解釈）
「カテゴリー」は、010で導入する楽器別の分類（`instrument`）のことと解釈した。
ブラスバンドは楽器ではなく編成（合奏）なので、`instrument` の値のひとつとして **`brass-band`** を足す。
別の場所（`category` の `column` / `announcement` など）に足す意図だった場合は、二階堂さんの確認のうえ、この依頼書を読み替えてください。

## 提案内容
1. `release.py` の楽器の辞書（010で `INSTRUMENT_TITLES` 等として作るもの）に追加:
   ```python
   "brass-band": "ブラスバンド",
   ```
   - 表示名は「ブラスバンド」。吹奏楽全般ではなく、金管中心の編成の話題（合奏・バンド運営・曲づくり）の記事に使う。
2. 010の許容値は `trumpet / trombone / horn / euphonium / tuba / all` だった。ここに `brass-band` を加えて、次の7値にする。
   ```
   trumpet / trombone / horn / euphonium / tuba / brass-band / all
   ```
3. 010の自動生成ルールをそのまま適用する:
   - `blog/instrument/brass-band.html`（まとめページ）が、**該当記事があるとき**に作られる。
   - 一覧ページの「楽器別」リンクに「ブラスバンド」が並ぶ。
   - 関連記事の選び方（同じ `instrument`（`all` 以外）が2番目）にも、そのまま効く。
   - `sitemap.xml` にも、まとめページが入る。
4. 既存の記事9本は、今のところ該当なし（`instrument` は変更しない）。
   今後、ブラスバンド向けの記事を書くときに、記事案の `instrument` 欄へ `brass-band` を書く。
5. 記事案の書式（`_drafts/README.md` など、管理者側で更新する箇所）の `instrument` の選択肢にも、`brass-band` を追記する。
6. 月ごとの「楽器月間」（`_queue/themes.md`）は楽器が中心なので、ブラスバンドは月間特集の対象にはせず、
   楽器をまたぐテーマ（合奏、バンド運営など）の置き場にする。

## 確認項目
- `release.py --no-release` を2回続けて実行しても差分が出ない（冪等）
- `instrument` に `brass-band` を指定した記事を1本置くと、`blog/instrument/brass-band.html` ができ、一覧の「楽器別」に出る
- 未知の値（綴り間違い）を入れても、公開が止まらず、`all` として扱われる（010の方針どおり）
- 既存記事・トップ・`sitemap.xml` に、意図しない変更がない

## 理由・根拠
- 読者の中心である吹奏楽・ブラスバンドの人が、自分向けの記事を一覧から選びやすくなる。
- 楽器の分類は辞書1行で増やせる設計（010）なので、今のうちに加えておくと、記事が増えてからの付け替えが要らない。

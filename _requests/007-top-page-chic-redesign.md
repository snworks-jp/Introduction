# 007 トップページをシックで高級感のあるデザインに変更

- 対象: Introductionサイト（トップページ `index.html` のみ）
- 優先度: 中
- 作成日: 2026-10-31
- ユーザー承認: 二階堂さん承認済み（デザイン案・キャッチコピー・セクション順）

## 提案内容

現在の「付箋ポップ」デザインを、黒基調＋金のアクセント、明朝体の見出し、細い罫線と広い余白の
落ち着いたデザインに変更したい。**文言・リンク・GA4タグ・BLOG自動更新の仕組みは変えない**（下記の例外のみ）。

### 1. 文言の変更（1か所）
- キャッチコピー（`.catch`）
  - 変更前: 音楽を続ける人の、ちょうどいい道具を作っています。
  - 変更後: **音楽と長く付き合う人のための、静かな道具。**
- サブ文（`.lede`）は今回は変更しない（「アプリの紹介と、演奏会カレンダーと、ちょっとしたBLOG」のまま）。
  ※セクション順を変えるため、後日「BLOG / 演奏会カレンダー / ScoreMate」への調整を別途検討。

### 2. セクション順の変更
上から **BLOG → 演奏会カレンダー → ScoreMate（アプリ）** の順にする。
- BLOGは**新しい記事が上（降順）**。現在の `release.py` の並びと同じなので、並びのロジックは変更不要。
- 見出しの小ラベルは `01 — JOURNAL`（BLOG）、`02 — CONCERTS`、`03 — APP` の連番にする。

### 3. 配色（CSS変数）
| 用途 | 色 |
|---|---|
| 背景 | `#141311` |
| 本文 | `#ece6da` |
| 補助文字 | `#a39b8c` |
| 説明文 | `#cfc7b8` |
| 罫線 | `#2c2a25` |
| アクセント（金） | `#c9a96a`（ホバー時 `#d8bd83`） |
| 枠・画像枠 | `#3a372f` / 背景 `#1b1a17` |

### 4. フォント
- 見出し・記事タイトル: 明朝体 `"Shippori Mincho", "Hiragino Mincho ProN", "Yu Mincho", serif`
- 本文: `"Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif`、太さ300、行間1.9
- 英字ラベル・ロゴ: `"Cormorant Garamond", "Times New Roman", serif`、文字間隔を広め（0.24〜0.4em）
- **Google Fontsなど外部フォントは使わず、システムフォントのフォールバックだけで実装することを推奨**
  （外部リクエストが増えるとプライバシーポリシーの記載・表示速度に影響するため）。
  どうしても欲しい場合は、フォントファイルをリポジトリ内に置く形を検討。

### 5. レイアウト（モックアップ準拠）
- 上部バー: 左に `SN WORKS`（英字ロゴ）、右にナビ `JOURNAL / CONCERTS / APP`（ページ内リンク）。下に細い罫線。
  現在のスクロール追従（sticky）は、不要なら外してよい。
- ヒーロー: 小ラベル `TOOLS FOR MUSICIANS`（金・英字）→ キャッチコピー（明朝・大きく）→ 短い金の横線 → サブ文。
  現在のSVGイラスト（五線譜・音符・浮遊アニメ）は**削除**。
- 各セクション間は細い罫線（`1px solid #2c2a25`）と大きめの余白（上下 64〜120px）。
- BLOG: 付箋カードをやめて**1行リスト**（左から 日付 / タイトル / 説明 / →）。上下に罫線。
  下に「BLOGをすべて見る →」（金の下線のテキストリンク）。
- 演奏会カレンダー: 左に見出し、右に説明・「無料」・「カレンダーを開く →」。
- ScoreMate: 左に見出し・説明・「Windows ／ 買い切り 580円」・「詳しく見る →」、右にスクリーンショット枠。
  スクリーンショット画像が用意できなければ、枠は設けず1カラムでよい。
- ボタン類は塗りつぶしをやめ、テキスト＋金の下線のみ。
- フッター: 左 `SN WORKS`、中央 プライバシーポリシー、右 © 2026 SN Works。

### 6. 実装時の注意（BLOG自動更新との整合）
- `scripts/release.py` の `card()` が出力するカードのHTML構造（`li > a.note.r1/r2 > strong / .d / .date`）は
  **変更せず、CSSだけで1行リスト表示にする**こと。`<!-- BLOG:START -->`〜`<!-- BLOG:END -->` はそのまま維持。
- `blog/index.html`（`release.py` が生成）や `pages/*.html` は今回は触らない。他ページへの展開は、
  トップの仕上がりを見てから別の依頼書で提案する。
- GA4タグ（`G-BRLV8TND0G`）、canonical、OGP、`googleb39988c901ff592a.html` は変更しない。
- スマホ幅（375px前後）で横スクロールが出ないこと、リンクのタップ領域が十分あること、
  本文と背景のコントラストが読みやすいことを確認する。
- `prefers-reduced-motion` は現状の考え方を踏襲（アニメーションは入れない）。

## 理由・根拠
- 二階堂さんから「ホームページが安っぽいのでシックで高級感を出したい」との要望。
- 原色（黄・珊瑚・青）の付箋、傾いたカード、丸ゴシック、浮遊アニメが「ポップ・カジュアル」な印象の主因。
  色数を絞り、罫線と余白で見せる構成にすると、同じ内容でも落ち着いた印象になる。
- モックアップ（Designキャンバス「SN Works トップページ（シック案）」）で承認済み。
  管理者がモックを開けない場合は、上記の配色・フォント・構成をそのまま実装してください。
- 補足: モックアップのBLOGは、2026-10-31時点のトップの4件（練習メニュー／タンギング／唇がバテる／ロングトーン）を使用。

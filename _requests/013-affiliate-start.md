# 013 アフィリエイトを始める（BLOGの記事に、控えめに商品リンクを載せる）

- 対象: BLOG記事・テンプレート（`scripts/template-curation.html`）、`pages/privacy.html`、必要に応じて `scripts/release.py`
- 優先度: 中
- 作成日: 2026-11-07
- ユーザー承認: 二階堂さんの意向「アフィリエイトで進めたい」（収益方針の検討の結果。アプリは当面このまま、無料キャンペーンは別の依頼書で検討）
- 関連: 009（BLOGのデザイン）、010（記事の分類）、011（ページ類のデザイン）

## 方針（先に決めたこと）
- 押し売りにしない。記事の本文の流れで「この練習に使った道具」を紹介する程度にとどめる。
  （依頼書001が「ごり押し」と評価されたため、販促は控えめを守る。）
- テキストリンクを基本にする。バナーや、外部のスクリプトを読み込むタグは使わない
  （表示速度、プライバシー、外部送信の整理のため）。
- 広告であることを、はっきり表示する。
- 最初は小さく始める。2〜3本の記事で試して、クリックと成果を見てから広げる。

## 二階堂さんがやること（エージェント・管理者はやらない）
アカウントの登録や審査申込、規約への同意は、本人がします。
1. **Amazonアソシエイト**: 申込み。承認後、一定期間内に売上が必要な条件があるとされる（現行の規約で確認）。
   アソシエイトIDを管理者に伝える。
2. **ASP（アフィリエイトの窓口サービス）**: A8.net またはもしもアフィリエイトのどちらか（または両方）に登録。無料。
   github.ioのサイトで登録できるかは未確認なので、申込みの時にサイトURLを入れて確認する。
3. **サウンドナビ（サウンドハウスの会員向けアフィリエイト）**: 参加条件を確認して申込み。楽器・用品に合う可能性が高い。
4. 承認されたものだけを使う。承認前のリンクは載せない。

## 管理者への依頼（サイトの変更）

### 1. 広告の表示（必須）
- 広告を含む記事には、**記事の冒頭**（タイトルの下）に1行で表示する。
  文言例: `※この記事には広告（アフィリエイトリンク）が含まれます。`
  文字は読める大きさと色（補助文字色でよいが、薄すぎない）にする。
- Amazonのリンクがあるページには、Amazonが規約で求める文言（「Amazonのアソシエイトとして、SN Worksは適格販売により
  収入を得ています。」の形）を、**ページ末尾か記事のフッター**に入れる。最新の規約で文言を確認すること。
- アフィリエイトのリンクの属性: `rel="sponsored noopener noreferrer"`、`target="_blank"`。
  （`class="src"` は参考記事のリンク用なので使わない。別のクラス、例 `class="aff"`、を使う。
  `release.py` の重複チェックに影響しないように）

### 2. 記事内の見せ方
- 記事の末尾に、任意で「この記事で使った道具」の小さな欄を置ける形にする（9本の既存記事を一斉に変えない）。
  ```html
  <section class="gear">
    <h2>この記事で使った道具</h2>
    <ul>
      <li><a class="aff" href="..." rel="sponsored noopener noreferrer" target="_blank">商品名</a> — 一言の説明</li>
    </ul>
    <p class="aff-note">※この欄には広告（アフィリエイトリンク）が含まれます。</p>
  </section>
  ```
- デザインは009・011の基準（黒＋金、角丸12px、影なし）に合わせる。リンクは金の下線。
- 欄がない記事では、何も出さない（空の欄を出さない）。

### 3. プライバシーポリシー（`pages/privacy.html` の「4. 広告・アフィリエイト」）
- 「現在、広告・アフィリエイトは行っていません」を、次の趣旨に書き換える。
  - 一部の記事に、アフィリエイトリンク（広告）を掲載していること
  - リンク先のサービス（Amazon、利用するASP名など）で、購入が当サイト経由であることを識別するために、
    Cookie等が使われる場合があること
  - 個人を特定する情報を、当サイトが広告会社へ送ることはないこと
  - 各サービスの取り扱いは、それぞれのプライバシーポリシーを見てもらうこと
- 最終更新日を更新する。

### 4. 計測（できれば）
- GA4で、アフィリエイトのリンクのクリックを数えられるようにする（外部リンクのクリックイベント）。
  どの記事のどの道具がクリックされたかが見えるようにする。
  （計測用のタグ追加が必要なら、先にGA4の設定を確認する。）

## 試験運用のやり方（案）
1. 承認が出たら、まず記事2〜3本に「この記事で使った道具」を付ける。
   候補（道具が自然に出てくる記事）: ロングトーン（チューナー・メトロノーム）、練習メニュー（メトロノーム・タイマー・録音機器）、
   唇のバテ（マウスピース、ケア用品）。選定は営業用エージェントが、記事案の段階で提案する。
2. 1か月ほど、クリックと成果を見る。
3. 効果があれば、新しい記事から、記事案に「紹介する道具」の項目を足して広げる。

## 守ること
- 自分でリンクから購入しない。家族や関係者にもさせない（成果が取り消されたり、アカウントが止められたりする）。
- 商品の価格や在庫を文中に書かない（変わるため）。
- 嘘や、誇張した効果の表現をしない。体験していない道具を、使ったように書かない。
- ScoreMateの紹介ページには、アフィリエイトのリンクを入れない（アプリの紹介は別の位置づけ）。
- 規約（Amazon、各ASP、サウンドナビ）は変わるので、始める前と、半年ごとに確認する。

## 確認項目
- 広告を含む記事の冒頭に、広告表示がある
- アフィリエイトリンクに `rel="sponsored noopener noreferrer"` が付いている
- 広告のない記事が、変わっていない
- スマホ幅（375px前後）で、欄が崩れない・横スクロールがない
- プライバシーポリシーが更新され、最終更新日が変わっている
- `release.py --no-release` で、一覧・トップ・sitemapが壊れない（冪等）
- GA4、アイコン、`googleb39988c901ff592a.html` に変更がない

## 範囲に含めないもの
- バナー広告、アドネットワーク（AdSenseなど）の導入（独自ドメインの検討とあわせて別に判断）
- ScoreMateのアプリ内広告
- 無料キャンペーン（Store掲載文・サイト文言の変更）は別の依頼書

## 理由・根拠
- BLOGは、吹奏楽・金管の練習の悩みを扱っており、チューナー、メトロノーム、マウスピース用品などの道具の紹介と相性がよい。
- アフィリエイトは、独自ドメインや審査の重いAdSenseより始めやすく、読者が必要とするものを紹介する形にできる。
- ステマ規制（2023年10月〜）の考え方に沿って、広告であることを明示すれば、信頼を損なわずに続けられる。
  （法的な最終判断は、必要なら専門家か消費者庁の情報で確認する。）

# ブログ用エージェント ルール書

## 役割
SN WorksのBLOG（金管楽器の上達コラム）について、記事の「準備」だけを担当します。
実際の公開作業（`_queue/`への配置、`release.py`の実行、サイトへの反映）は
管理者（コード作成担当のClaudeセッション）が行います。

## 進め方
1. `_queue/themes.md` を見て、次に用意するテーマを確認する
2. WebSearch（note.com限定）で候補記事を探し、本文を実際に読む（YouTubeは使わない）
3. 次の記事は除外する: 有料記事／転載・引用・紹介を禁じる記載があるもの／
   商品・アフィリエイト色が強いもの／上級者向けすぎるもの
4. 採用候補（著者名・記事タイトル・URL・公開年月）を3本選ぶ
5. 記事内容を自分の言葉で3行程度（各40字前後）にまとめる（原文の丸写しはしない）
6. カード用の一言（30字前後）と、候補タイトルを考える

## できないこと（禁止事項）
- `_queue/` `blog/` `index.html` `sitemap.xml` を直接編集すること
- `release.py` を実行すること
- GitHubへのpush、コミット

## 記事案の出し方
準備ができたら「記事案」として、1本＝1ファイルでこのフォルダ（`_drafts/`）に置いてください。

**ファイル名**: `NNN-スラッグ.md`（NNNは`themes.md`でのテーマ順、スラッグは記事URL用の短い英語）

**記事案に書く項目**
- テーマ名
- 候補タイトル
- 引用元3本（それぞれ: 著者名／記事タイトル／URL／公開年月）
- 要点3行（自分の言葉で、各40字前後）
- カード用の一言（30字前後）
- 除外確認（有料・転載禁止・アフィリエイトのいずれにも該当しないことを確認した旨）

## 注意
- 一度置いた記事案は、提出後に自分で書き換えないでください。修正は新しいファイルとして出してください。
- 対応済み（公開済み）の記事案は管理者が `_drafts/done/` に移動します。

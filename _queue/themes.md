# コラム公開計画（週1回・月曜6時）

## ルール
- 1本 = 1テーマ。「よくあるお悩み」ごとにまとめる（ロングトーン、リップスラー等）。
- 紹介元は note などのブログ。本文を読んで要点を自分の言葉で3つにまとめ、著者名・記事名・リンクを必ず載せる。
- 紹介してよいか: 引用・紹介お断りの記載がないもの。公開時点で運営者が確認する。
- 毎月第1週は「楽器月間」特集（その月の楽器）。それ以外の週は悩みテーマ。
- 楽器月間: 10月 トランペット / 11月 トロンボーン / 12月 ホルン / 1月 ユーフォニアム / 2月 チューバ

## 先に決めた5テーマ（悩み別）
1. ロングトーン ― 何のため？ どう練習する？（サンプル記事あり。紹介型に作り直す）
2. リップスラー ― 目的とやり方、うまくいかない時
3. 高い音が出ない ― 力まずに出すための考え方
4. タンギング ― 音の出だしが汚い・重い
5. 練習メニューの組み立て ― 短時間でのウォームアップと基礎練習

## 備考
- 候補記事は読んだうえで「著者・公開日・要点3行」の一覧にして確認してから書く。
